# Firebase Temples Collection Setup

## Collection Name
`temples`

## Firestore Document Structure

```typescript
{
  id: string;                    // Auto-generated by Firestore
  name: string;                  // Required: Temple name (e.g., "Shivalayam Temple")
  fullName?: string;             // Optional: Full name (e.g., "Sri Sivalayam Temple")
  area: string;                  // Required: Area/location (e.g., "Chennuru Center")
  landmark: string;              // Optional: Landmark description
  imageUrl?: string;             // Optional: Main temple image URL (from ImgBB)
  galleryImageUrls?: string[];   // Optional: Array of gallery image URLs (from ImgBB)
  importance?: string;           // Optional: Importance/history description
  timings?: string;              // Optional: Temple timings (e.g., "6:00 AM - 8:00 PM")
  userId: string;                // Required: Firebase Auth UID of the creator
  createdAt: Timestamp;          // Auto-generated timestamp
  updatedAt: Timestamp;          // Auto-updated timestamp
}
```

## Security Rules

Add the following rules to your Firestore Security Rules:

```javascript
match /temples/{templeId} {
  // Anyone can read temples
  allow read: if true;
  
  // Only authenticated users can create temples
  allow create: if request.auth != null 
    && request.resource.data.userId == request.auth.uid
    && request.resource.data.name is string
    && request.resource.data.area is string;
  
  // Only the owner can update their own temples
  allow update: if request.auth != null 
    && resource.data.userId == request.auth.uid
    && request.resource.data.userId == resource.data.userId;
  
  // Only the owner can delete their own temples
  allow delete: if request.auth != null 
    && resource.data.userId == request.auth.uid;
}
```

## Migrating Existing Data

If you have existing temple data in the codebase, you can manually add it to Firestore:

1. Go to Firebase Console > Firestore Database
2. Create a new collection named `temples`
3. For each temple, create a document with the structure above
4. Use a temporary userId (you can update it later with actual user IDs)

## Image Upload

Temple images are uploaded to ImgBB using the `MultiImageUpload` component:
- Main image: Single image upload (max 1)
- Gallery images: Multiple images (max 4)

All image URLs are stored as strings in the `imageUrl` and `galleryImageUrls` fields.
